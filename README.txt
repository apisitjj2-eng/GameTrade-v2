GameTrade v2 — Local Demo
========================

สิ่งที่มีในเวอร์ชันนี้
- หน้าแรก / ตลาด / ลงขาย / คำสั่งซื้อ / รายการโปรด / บัญชีของฉัน / ช่วยเหลือ
- สมัครสมาชิกและเข้าสู่ระบบผ่าน backend และ SQLite
- เปลี่ยนบทบาทผู้ซื้อ/ผู้ขาย
- สร้างประกาศขาย ค้นหา กรองตามเกม/งบ และเรียงตามราคา
- เปิดดูรายละเอียดรายการและบันทึกรายการโปรด
- สร้างคำสั่งซื้อทดลอง ผู้ขายยืนยันส่งมอบ ผู้ซื้อยืนยันรับมอบ และเปิดข้อพิพาท
- หน้าแอดมินสำหรับจัดการข้อพิพาท (ต้องตั้งบัญชีแอดมินด้วยตนเอง)
- แอนิเมชันเปลี่ยนหน้าและการ์ด รองรับมือถือ

ข้อสำคัญ
- เป็นต้นแบบในเครื่องเท่านั้น ไม่มีการชำระเงินจริง ไม่มี PromptPay/Payment Gateway และไม่มีระบบพักเงินจริง
- ห้ามเปิดใช้งานสู่สาธารณะหรือใช้เก็บข้อมูลสำคัญในเวอร์ชันนี้
- ตรวจสอบกฎของเกมและข้อกำหนดผู้ให้บริการก่อนซื้อขายบัญชีเกม

ติดตั้งบน Linux Mint
1) แตกไฟล์ ZIP
2) เปิด Terminal แล้วเข้าโฟลเดอร์ที่มี package.json เช่น:
   cd ~/ดาวน์โหลด/GameTrade-v2
   (ถ้าแตกไฟล์ไปที่อื่น ให้เปลี่ยน path ให้ตรง)
3) ตรวจสอบ Node:
   node --version
   แนะนำ Node.js 20 หรือใหม่กว่า
4) ติดตั้ง dependency:
   npm install
5) เปิดเว็บ:
   npm start
6) เปิดเบราว์เซอร์ที่ http://localhost:3000

ถ้าเคยมีฐานข้อมูลเก่าจาก GameTrade เวอร์ชันก่อนหน้า
ไฟล์ gametrade.db จะถูกใช้ซ้ำโดยอัตโนมัติเมื่อวางไฟล์ไว้ในโฟลเดอร์เดียวกับ server.js
หากต้องการเริ่มฐานข้อมูลว่าง ให้ปิดเซิร์ฟเวอร์ก่อน แล้วสำรอง/เปลี่ยนชื่อ gametrade.db

หมายเหตุเรื่อง Node.js
Node.js 18 อาจไม่รองรับ dependency บางตัวในอนาคต หาก npm install แจ้งปัญหาเวอร์ชัน ให้ติดตั้ง Node.js 20/22 LTS ก่อน
